중립 원색은 이 5개만 사용해요. 의미 색의 옅은 면·선택 면·떠 있는 요소의 반투명 가림은 별도 회색 단계가 아닌 역할별 합성이에요. 표 머리는 기존 neutral-0을 재사용해요. 입력 경계와 정상 보조 글자를 같은 흐린 회색으로 묶지 않아요. `neutral-400`은 비텍스트 3:1 기준의 경계이며 정상 글자에는 최소 4.5:1인 `neutral-600`을 써요(V4·V10).

`neutral-50`/흰 면의 낮은 대비는 카드나 표의 **비조작 구분**에만 써요. 조작 요소의 경계에는 `neutral-400`, 포커스에는 파랑을 써요. 정보는 선 하나나 색 하나에만 의존하지 않아요(V1·V8·V10).

표 머리는 `table-header` 역할을 기존 흰 surface(neutral-0, `#FFFFFF`)에 연결해요(D17). CSS `--table-header: var(--surface)`·Tailwind `bg-table-header` 이름을 유지해요. 표 전체의 흰 면이 옅은 회색 페이지와 구분되고, 같은 흰 면인 머리와 본문은 neutral-950/600 굵기 머리글·기존 input 색 아래1px 경계로 구분해요. 머리글 foreground/흰 면 대비는14.86:1이에요(V1·V4·V10).

## 3. 글자

서체는 기존 Pretendard를 유지해요. 코드·ID·라벨 원문은 기존 mono 계열을 유지해요. 새 폰트 패키지를 설치하지 않아요(V4·P10).

|---|---|---|---|

## 5. 모서리·그림자

| 역할 | 값 | 용도·원칙 | 대비 |
|---|---|---|---|
| control | 8px | 버튼·입력·상태 칩. 같은 화면 안 작은 요소를 통일해요(V5). | 해당 없음 |
| card | 12px | 평평한 카드·구획. 큰 면을 부드럽게 묶어요(V1·V5). | 해당 없음 |
| overlay | 16px | 떠 있는 모달·팝오버·토스트(V5·V6). | 해당 없음 |

앱의 `rounded-md`→8, `rounded-lg`→12, `rounded-xl`→16으로 제안해요. `rounded-sm`은 작은 별도 단계를 만들지 않고 control 8로 합쳐요. 기존 `--radius`는 card 12px를 가리키고, 현재 `--radius - 2px` 계산은 md 8px로 명시해요. Ravvit 입력의 기존 12px 예외는 `rounded-lg`의 12px를 사용해 유지하는 안이에요. 공개 props 의미는 바꾸지 않아요(P2·P5·V5).

### 6-3. Ravvit 표시 연출 — 별도 승인 항목

**추천안은 완성된 답변을 즉시 모두 표시**하는 안이에요. 기존 D8의 문자 공개 연출만 대체하고 SSE 요청·이벤트 스키마·불투명 history·중단·재생성·대화 유지·스크롤 추종 조건은 바꾸지 않아요. 현재 코드의 목표 1600ms 공개는 사람 확인 1의 H3 승인으로 단계 5에서 대체해요(P9·M1·M5).

이 문서와 정적 견본에는 움직이는 코드가 없어요. 모션 시간은 설계값이며 실제 인터럽트·origin·reduced 동작의 통과 판정이 아니에요. 구현 후 `review-animations`와 실제 브라우저로 확인해요.

H1·H2·H3 모두 2026-11-14 승인받았어요. H2는 중립 전환안으로 확정했으며 기존 제공자 이름·인증 동작·2열 골격을 유지해요. 단계 5에서 제품 자산을 교체해요.

행 키보드 진입·입력 접근 이름·스킵 링크 등 스타일 밖의 접근성 동작 보완은 이 문서 승인만으로 진행하지 않아요. 후속 별도 계획에서 범위를 확인해요. DS-00~03·명세 인덱스·확정 결정의 실제 이관은 승인받은 범위로 단계 3 계획에 적어요.

## 10. 견본의 검증 범위

정적 견본은 토큰의 조합·대비·위계·문구를 보는 문서예요. 앱 스타일·모션 동작·API 회귀의 검증 결과는 아니에요. 정적 로딩 모양과 오류 문구는 예시임을 표시하며 실제 대기나 장애가 있다고 표현하지 않아요(V8).

| 확인 | 방법·기록 |
|---|---|
| 값 일치 | 견본의 `token-data` JSON·CSS 정의와 이 문서의 표를 대조해요 |
| 대비 | §2-4의 전경·배경·합성 쌍을 다시 계산하고 브라우저 색도 확인해요 |
| 표시 | agent-browser로 Pretendard 폰트 로드·1440px 폭·전체 내용·넘침을 확인하고 PNG를 직접 열어요 |

공용 변수·스타일 적용은 전체 화면의 개편 완료를 뜻하지 않아요. 고유 차트/게이지·로그인·Ravvit·QA 문구는 해당 단계 결과에서 별도로 확인해요.

### 모션 구현의 보존 경계

키보드로 시작한 overlay는 instant0ms로 표시해요(M2·M6). Select는 설치된 Radix가 닫을 때 즉시 unmount하므로 기존 즉시 닫힘을 보존해요. menu-exit90ms는 Presence를 제공하는 Dropdown 계열에 적용하며, Select의 상태/포커스 생명주기를 exit 연출을 위해 바꾸지 않아요(P5·M2).

### 단계5D 부분 MAU 역할 연결

`--chart-mau-partial: var(--fg-disabled)`는 승인 N400을 부분 집계 막대에 연결해요. 새 색/기존 변수 의미 변경 없이 불투명3:1이상 경계를 유지해요(V8·V10). 완료 막대는 기존 chart-mau N600, 부분 설명/inProgress·기간·값은 D7 그대로예요.

### 단계5E 로그인 구조 비율

`--login-panel-ratio: 559 / 720`·`aspect-login-panel`은 기존 일러스트 intrinsic 비율을 유지하는 구조 토큰이에요. 1024폭/50%열/56버튼과 원래 카드 높이를 보존해요(P5). 기존 brand-* 의미 alias/asset은 호환 보존, 제공자 UI는 공용 outline을 사용해요.
