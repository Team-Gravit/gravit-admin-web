## 5. 대비·접근성·UI 점검

`web-design-guidelines` 스킬의 최신 지침을 2026-11-13에 받아 실제 사용 파일에 적용했어요. 데스크톱 SPA라는 저장소 제약을 유지했으며 모바일·다크 모드·SSR 전용 항목은 적용하지 않았어요. 이 단계에서는 발견 사항을 고치지 않고 승인할 변경 범위로 남겨요.

### 5-1. 대비

브라우저 `getComputedStyle`의 렌더링 RGB로 계산했어요. CSS 주석의 hex 대신 실제 값이 기준이에요. sRGB를 선형화한 상대 휘도에서 `(밝은 L + 0.05) / (어두운 L + 0.05)`를 사용했어요. 픽셀 안티앨리어싱까지 자동 판정한 결과는 아니에요.

비활성 컨트롤의 흐린 글자를 일반 본문과 같은 실패 항목으로 세지 않았어요. 모든 색 쌍의 대비를 확인한 것은 아니며 새 토큰은 단계 2에서 사용 쌍마다 별도로 계산해요(V10).
